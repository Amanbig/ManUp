# ManUp v0.4.0 — Workspaces, Scoped Keys & Light Mode

## 🚀 What's New in v0.4.0

ManUp v0.4.0 is a major feature release introducing a completely redesigned Project Workspace interface, Project-Scoped API Keys, direct name-based secret querying, native Light/Dark theme support, and an upgraded official CLI (`manup-cli` v0.3.0).

---

### 🖥️ Redesigned Projects Dashboard & Workspace UI
- **Projects Dashboard**: Replaced the flat secrets listing with an intuitive project overview showcasing real-time environment status cards, member counts, and quick-action modals.
- **Tabbed Project Workspace**: Seamlessly navigate between environments (Development, Staging, Production) within a dedicated project workspace.
- **Auto-Wrapping & Auto-Resizing Secret Editor**: Multi-line values, certificates, and RSA/SSH private keys expand and wrap cleanly without horizontal overflow.
- **Bulk `.env` Import & Export**: Import existing `.env` files with automatic key-value parsing and syntax preview, or bulk insert multiple secrets at once.

---

### 🔑 Project-Scoped API Keys & Granular RBAC
- **Project Isolation**: API keys can now be scoped to an individual project or provisioned organization-wide, enforcing zero-trust boundaries across microservices and CI/CD jobs.
- **Fine-Grained Scopes**: Choose between `full` (read/write) or `read-only` access tokens.
- **Intelligent Scoping**: Scoped API keys automatically infer their target project on API requests without requiring explicit project identifiers.

---

### 📡 Direct Name-Based Query API
- **Human-Friendly Environment Queries**: Retrieve decrypted secrets using environment names, IDs, or common abbreviations:
  - `GET /api/secrets?env=production`
  - `GET /api/secrets?env=dev&project=backend-api&format=dotenv`
- **Multi-Format Responses**: Native support for JSON (`format=json`), raw `.env` text (`format=dotenv`), and key-value maps (`format=kv`).
- **Bulk Operations**: Added `POST /api/secrets/bulk` for batch secret insertions and updates.
- **Resolution Headers**: Responses include resolved metadata headers (`X-Environment-Id`, `X-Environment-Name`, `X-Project-Id`, `X-Project-Name`).

---

### 🌓 Native Light & Dark Theme Support
- **Built-in Theme Switcher**: Full support for Dark Mode, Light Mode, and System Preference detection.
- **High-Contrast Typography & Visuals**: Redesigned color palettes, warning banners, error callouts, and empty states optimized for high legibility in light mode.

---

### 💻 Official CLI (`manup-cli` v0.3.0)
- **Name & Abbreviation Targeting**: Run commands and fetch secrets using environment names without needing UUIDs:
  ```bash
  manup run -e dev -- npm start
  manup run -p backend -e prod -- npm test
  ```
- **API Key Management via CLI**: Provision and revoke project-scoped access tokens:
  ```bash
  manup keys ls
  manup keys create ci-token --scope full --project backend --days 90
  ```
- **Scriptable Workspace Linking**: Automate linking in CI/CD or Dockerfiles:
  ```bash
  manup init -p backend -e dev
  ```
