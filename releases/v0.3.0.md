# ManUp v0.3.0 — Security & Permissions Hardening

## 🔒 Security & Permissions Hardening

- **Scoped API Keys**: Keys can now be created with `full` or `read-only` scope. A `read-only` key is rejected on any mutating request (POST, PUT, DELETE), even if the underlying user could otherwise write.
- **Brute-Force Protection on Auth**: `/register` (5/min) and `/login` (10/min) are now rate-limited per IP address.
- **Password Confirmation Required**: Changing your email, username, or deleting your account requires current password re-verification.
- **Organization Safety Controls**:
  - The organization owner can no longer delete their own account (prevents ownerless organizations).
  - Only `owner` or `admin` can update organization details or manage members.
  - The organization owner cannot be removed via member management endpoints.

## 🛠️ Other Changes

- **Client UI Refactor**: Modularized sidebar, modals, and views out of the main application file for enhanced maintainability.
- **Formatting & Configuration**: Repository-wide Prettier standards and lint configuration.
