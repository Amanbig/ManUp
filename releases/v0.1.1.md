# ManUp v0.1.1 — First Release

ManUp is a self-hosted, open-source secrets manager — a lightweight alternative to Infisical / HashiCorp Vault.

### Highlights

- **Centralized secrets vault** with encrypted envelope storage
- **RBAC** — Owner / Admin / Viewer roles, scoped to projects and environments
- **Project & environment isolation** (Development / Staging / Production)
- **Programmatic API keys** for CI/CD, with expiration and rate limiting
- **Cookie-based auth** with refresh tokens and `httpOnly` secure cookies
- **Self-hosting** via Docker / Docker Compose — embedded PGlite or external Postgres
- **Dashboard** — React 19 + Tailwind CSS v4 dashboard
