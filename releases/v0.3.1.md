# ManUp v0.3.1 — Official CLI Integration & Docs

## 🚀 What's New in v0.3.1

### 💻 Official CLI Integration & Documentation
- **CLI Documentation**: Integrated official documentation for **`manup-cli`** (`v0.2.0`), covering global installation, direct credentials login, workspace linking (`manup init`), and zero-disk process secret injection (`manup run`).
- **Web Documentation Site**: Built a mobile-responsive HTML documentation website in `docs/index.html` featuring live search, interactive quickstart guides, and high-resolution platform screenshots.

### 🔐 Server Authentication & Token Refresh Enhancements
- **Multi-Client Token Refresh**: Enhanced `POST /api/users/refresh` and `POST /api/users/login` endpoints to return and accept `refreshToken` in JSON payloads and headers, enabling CLI and API clients to perform automatic session token refresh.
